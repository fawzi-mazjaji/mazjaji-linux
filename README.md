---

## 📖 عن المشروع

هذا المشروع هو **صدقة جارية** تهدف إلى جعل سطر أوامر لينكس صديقاً للمستخدم العربي، عن طريق تحويل الأوامر الإنجليزية إلى أوامر عربية سهلة الاستخدام، دون فقدان أي من قوة النظام أو مرونته.

## 🕌 لماذا هذا المشروع؟

لأننا **أمة "إقرأ"**، وأول كلمة نزلت في رسالة خير البشر ﷺ كانت تحثنا على طلب العلم بلا حدود.

ليس لأننا نرفض تعلم اللغات الأخرى، بل لأننا نؤمن بأن **التكنولوجيا يجب أن تخدم الإنسان**، وليس العكس. نهدف إلى تمكين كل عربي (مسلماً كان أو غير مسلم) من امتلاك ناصية التقنية دون أن يكون حاجز اللغة عائقاً أمامه.

هذا المشروع هو **اللبنة الأولى** في طريق طويل؛ لا نقف عند حدود تعريب الواجهات الرسومية، بل نسعى - خطوة بخطوة - إلى أن تمتد لغتنا الجميلة إلى **لب النظام**، ليكون لينكس صديقاً للعربي في أعمق طبقاته.

نسأل الله التوفيق، ونسعد بكل من يسير معنا في هذا الدرب.

## 🛠️ التثبيت (سطر واحد)

افتح الطرفية (Terminal) وانسخ هذا الأمر ثم اضغط Enter:

```bash
bash <(curl -s https://raw.githubusercontent.com/fawzi-mazjaji/mazjaji-linux/main/install.sh)
```

بعد انتهاء التنفيذ، ستكون جميع الأوامر العربية جاهزة للاستخدام فوراً.

**للتحقق من نجاح التثبيت**، اكتب:

```bash
اين-انا
```

إذا ظهر لك المسار الكامل للمجلد الحالي، فهذا يعني أن التثبيت تم بنجاح.

> **ملاحظة:** هذا الأمر يسحب دائماً **أحدث إصدار** تلقائياً. إذا كنت قد استخدمته سابقاً، فأنت الآن تستخدم v0.2 دون أن تدري!

## 📋 أوامر الإصدار الأول (v0.1) – التنقل والاستكشاف

| الأمر العربي | الأمر الإنجليزي | الشرح المختصر |
| :--- | :--- | :--- |
| `اين-انا` | `pwd` | يعرض المسار الكامل للمجلد الحالي. |
| `انتقل` | `cd` | ينتقل إلى مجلد آخر (مثل `انتقل /home`). |
| `ارجع` | `cd -` | يعود إلى المجلد السابق. |
| `اعرض` | `ls` | يعرض محتويات المجلد الحالي (عرض بسيط). |
| `اعرض-مخفي` | `ls -a` | يعرض جميع الملفات بما فيها المخفية. |
| `اعرض-تفصيل` | `ls -l` | يعرض محتويات المجلد مع التفاصيل. |
| `اعرض-كامل` | `ls -la` | يعرض جميع الملفات مع التفاصيل. |
| `اعرض-حجم` | `ls -lh` | يعرض المحتويات مع حجم مقروء (K، M، G). |
| `اعرض-ممتد` | `ls -R` | يعرض المحتويات بشكل متكرر. |
| `اعرض-زمني` | `ls -lt` | ترتيب حسب تاريخ التعديل (الأحدث أولاً). |
| `اعرض-زمني-عكسي` | `ls -ltr` | ترتيب حسب تاريخ التعديل (الأقدم أولاً). |
| `اعرض-كبير` | `ls -lS` | ترتيب حسب الحجم (الأكبر أولاً). |
| `نوع-الملف` | `file` | يحدد نوع الملف. |
| `تصفح` | `less` | يعرض ملفاً نصياً بصفحات متتالية. |
| `نوع` | `type` | يبين نوع الأمر. |
| `اين` | `which` | يعرض مسار الملف التنفيذي. |
| `مساعدة` | `help` | شرح مختصر للأوامر المدمجة. |
| `اخرج` | `exit` | يغلق الطرفية الحالية. |

## 📋 أوامر الإصدار الثاني (v0.2) – إدارة الملفات والمجلدات

| الأمر العربي | الأمر الإنجليزي | الشرح المختصر |
| :--- | :--- | :--- |
| `انشئ-مجلد` | `mkdir` | إنشاء مجلد جديد. |
| `انشئ-مسار` | `mkdir -p` | إنشاء مجلدات متداخلة. |
| `انشئ-ملف` | `touch` | إنشاء ملف فارغ أو تحديث تاريخه. |
| `انسخ` | `cp -i` | نسخ ملف (مع طلب تأكيد). |
| `انسخ-مجلد` | `cp -r` | نسخ مجلد بجميع محتوياته. |
| `انسخ-كامل` | `cp -a` | نسخ مع الحفاظ على جميع الخصائص. |
| `انقل` | `mv -i` | نقل أو إعادة تسمية. |
| `احذف-ملف` | `rm` | حذف ملف (بدون تأكيد) – **للمتقدمين**. |
| `احذف-ملف-بامان` | `rm -I` | حذف ملف مع تأكيد مرة واحدة. |
| `احذف-ملف-بامان-تام` | `rm -i` | حذف ملف مع تأكيد لكل ملف. |
| `احذف-مجلد` | `rm -r` | حذف مجلد ومحتوياته – **للمتقدمين**. |
| `احذف-مجلد-بامان` | `rm -rI` | حذف مجلد مع تأكيد مرة واحدة. |
| `احذف-مجلد-بامان-تام` | `rm -ri` | حذف مجلد مع تأكيد لكل ملف. |
| `احذف-مجلد-فارغ` | `rmdir` | حذف مجلد فارغ فقط. |
| `احذف-مسار-فارغ` | `rmdir -p` | حذف مجلد فارغ ثم الأب إن أصبح فارغاً. |
| `معلومات-ملف` | `stat` | عرض معلومات تفصيلية عن ملف. |

> ⚠️ **تحذير:** أوامر الحذف بدون `بامان` تحذف نهائياً ولا يمكن استرجاعها. استخدمها بحذر، ويفضل للمبتدئين استخدام الأوامر التي تحتوي على `بامان`.

## 🎁 الهدية: `نظف-فارغ`

أداة إضافية لتنظيف المجلدات الفارغة تلقائياً:

```bash
نظف-فارغ .          # يحذف كل المجلدات الفارغة في المجلد الحالي
نظف-فارغ /path      # يحذف المجلدات الفارغة في مسار محدد
نظف-فارغ --dry-run  # يعرض المجلدات التي سيتم حذفها دون حذف فعلي
```

هذه الأداة آمنة جداً لأنها تعتمد على `rmdir` الذي لا يحذف إلا المجلدات الفارغة.
