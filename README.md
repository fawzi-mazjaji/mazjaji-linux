هذا المشروع هو **اللبنة الأولى** في طريق طويل؛ لا نقف عند حدود تعريب الواجهات الرسومية، بل نسعى - خطوة بخطوة - إلى أن تمتد لغتنا الجميلة إلى **لب النظام**، ليكون لينكس صديقاً للعربي في أعمق طبقاته.

نسأل الله التوفيق، ونسعد بكل من يسير معنا في هذا الدرب.

## 📦 الإصدار الأول: أوامر التنقل والاستكشاف (v0.1)

### 🎯 ما يحتويه هذا الإصدار؟

- **18 أمراً عربياً** تغطي احتياجات التنقل والاستكشاف الأساسية.
- الأوامر الأساسية: `اين-انا`، `انتقل`، `ارجع`، `اعرض`، `نوع-الملف`، `تصفح`، `نوع`، `اين`، `مساعدة`، `اخرج`.
- مشتقات `اعرض` مع خياراتها المدمجة: `اعرض-مخفي`، `اعرض-تفصيل`، `اعرض-كامل`، `اعرض-حجم`، `اعرض-ممتد`، `اعرض-زمني`، `اعرض-زمني-عكسي`، `اعرض-كبير`.

---

## 🛠️ كيفية تثبيت الإصدار الأول

لتثبيت الأوامر العربية على نظامك، اتبع الخطوة التالية:

1. افتح الطرفية (Terminal).
2. انسخ والصق هذا الأمر ثم اضغط Enter:

```bash
bash <(curl -s https://raw.githubusercontent.com/fawzi-mazjaji/mazjaji-linux/main/install.sh)
```

3. بعد انتهاء التنفيذ، ستكون جميع الأوامر العربية جاهزة للاستخدام فوراً.

**للتحقق من نجاح التثبيت**، اكتب:
```bash
اين-انا
```
إذا ظهر لك المسار الكامل للمجلد الحالي، فهذا يعني أن التثبيت تم بنجاح.

## 📋 جدول الأوامر المتوفرة في الإصدار الأول

| الأمر العربي | الأمر الإنجليزي | الشرح المختصر |
| :--- | :--- | :--- |
| `اين-انا` | `pwd` | يعرض المسار الكامل للمجلد الحالي. |
| `انتقل` | `cd` | ينتقل إلى مجلد آخر (مثل `انتقل /home`). |
| `ارجع` | `cd -` | يعود إلى المجلد السابق. |
| `اعرض` | `ls` | يعرض محتويات المجلد الحالي (عرض بسيط). |
| `اعرض-مخفي` | `ls -a` | يعرض جميع الملفات بما فيها المخفية. |
| `اعرض-تفصيل` | `ls -l` | يعرض محتويات المجلد مع التفاصيل (الصلاحيات، الحجم، التاريخ). |
| `اعرض-كامل` | `ls -la` | يعرض جميع الملفات (بما فيها المخفية) مع التفاصيل. |
| `اعرض-حجم` | `ls -lh` | يعرض المحتويات مع حجم مقروء (K، M، G). |
| `اعرض-ممتد` | `ls -R` | يعرض المحتويات بشكل متكرر ليشمل المجلدات الفرعية. |
| `اعرض-زمني` | `ls -lt` | يعرض المحتويات مرتبة حسب تاريخ التعديل (من الأحدث إلى الأقدم). |
| `اعرض-زمني-عكسي` | `ls -ltr` | يعرض المحتويات مرتبة حسب تاريخ التعديل (من الأقدم إلى الأحدث). |
| `اعرض-كبير` | `ls -lS` | يعرض المحتويات مرتبة حسب الحجم (من الأكبر إلى الأصغر). |
| `نوع-الملف` | `file` | يحدد نوع الملف (نص، صورة، برنامج، ...). يجب أن يتبعه اسم ملف. |
| `تصفح` | `less` | يعرض ملفاً نصياً بصفحات متتالية (للتمرير استخدم الأسهم أو Page Up/Down). |
| `نوع` | `type` | يبين نوع الأمر (مدمج، اسم مستعار، خارجي، دالة). |
| `اين` | `which` | يعرض المسار الكامل للملف التنفيذي لأمر معين (للأوامر الخارجية فقط). |
| `مساعدة` | `help` | يعرض شرحاً مختصراً عن الأوامر المدمجة في الصدفة (مثل `مساعدة cd`). |
| `اخرج` | `exit` | يغلق الطرفية الحالية. |
